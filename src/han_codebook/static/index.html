研究流程與系統架構

本工作台不是輸入密電就能自動證實明文的「解密器」，而是協助研究員將可觀察情報、候選詞與競爭假說整理成可追溯的分析過程。數字碼組可能對應單字、詞組或固定句；在沒有可靠逐碼明文對照前，模型提供的中文都屬未驗證假說。

建議操作順序：建立案例 → 輸入密電／觀察 → LLM 建議詞庫 → 人工覆核與補充多個想法 → 事件與碼組交叉推論 → 檢查解讀與差異 → 撤銷／修正 → 再次求解。

七個操作階段

01｜建立研究案例

按頁首「＋ 建立空白案例」，輸入案例代號。新增每封密電，依空白分隔數字碼組。修改完按「套用此封情報」，並用「另存案例」寫入本機。尚無明文也可以開始。

02｜記錄外部觀察

輸入收發者、收報時間、目擊日期／行動、來源與可信度。用時序關聯查看可能在事件前後出現的電文。時間接近不代表語意相關，清單保留「完全無關」。

03｜建立候選詞庫

可自行新增詞組／範例句，或明確確認後呼叫 config.yaml 指定的內網 LLM，讓它依密文及背景情報提出待審詞彙。模型建議不會自動納入詞庫。

04｜執行推論

統計求解器先提出初始碼本，再依選擇的 LLM 回合數提出候選與重新評分。0 回合完全離線；大於 0 回合才會向配置的本機／內網模型送出資料。主要結果是最後一輪。

05｜保留競爭假說

一個碼組可以記錄多個研究員／LLM／觀察來源的詞組，分別標示「待審、優先考慮、否定」。另有偏好、排除與試鎖供局部實驗，這些都不是 verified anchor。

06｜追蹤改變的理由

比較更新前後的碼組 Top-1、逐輪統計目標與模型建議。如果調高提示權重只增加採納數，卻沒有增加盲測正確率，不能宣稱破譯有進展。

07｜撤銷、修正與評測

研究員可以復原／重做標註，選擇新假說再重新求解。合成基準的正解只供推論完成後評分，不得放回模型提示或當作真實歷史破譯成功。

四層證據與求解架構

證據層如何使用重要界線
電文與元數據數字碼組、電文時序、收發者、領域線索。統計／bigram 形成初始詞序先驗。重複出現不等於找到真正明文。
第三方動態觀察目擊事件與多封密電的日期距離、來源可信度、可能相關碼組，產生跨電文假說供 LLM 或研究員查核。目前是保守的時間關聯候選，尚非經校準的因果事件推理；可能全部無關。
LLM 與人工建議先探索候選詞庫，再提出碼組對應。研究員可標示支持、否定或試鎖；重新求解產生可比較版本。候選詞、模型信心、統計分數都不等於破解成功率。
可靠已知明文有可信來源且逐碼對齊的明密文對，才可進入已驗證錨點。未證實的模型建議不得升格為已知明文。

多輪的意思與資料保存

Round 0 是統計初始求解。之後每一輪由模型參考現有候選，提出建議，再由統計求解器整批重新計算。主畫面呈現最後一輪；「逐輪紀錄」能查看過程。CMD 與 GUI 是各自獨立的執行，不會自動共用另一個工作的輸出。

「另存案例」保存目前密電、詞庫與候選想法，但想法庫 Undo／Redo 快照僅在本次網頁工作階段有效。輸出結果與稽核會存於本機 artifacts 目錄。若研究案例於 LLM 呼叫期間切換或修改，舊工作回覆不得採納到新案例。

安全與有效性：本機介面綁定 127.0.0.1；LLM 網路請求需明確選擇與確認，僅發往設定且允許的私有端點。資料與密碼組請視為敏感研究材料。Vercel 公開 PoC 只做合成 Mock 展示，沒有此本機真實模型流程。

執行研究

所有密碼組維持原始字串，已知對齊是確定錨點；收發者與第三方觀察只作推測先驗。

0＝離線；1～20 為內網 LLM 回合，不保證回合多就更準確
額外離線求解；評估的是遮蔽後的統計求解器，不是 LLM 各輪正確率，也不會自動選回合。
需先詢問全部未知碼；沒有新增引用／候選、Top-5 未變，才計停滯。不是正確率判斷。
停止的只有詞庫生成；數字碼組推理仍繼續，人工審核模式不自動略過。

動態模式每回合先由內網 LLM 依目前密文、跨報目擊與上一輪未驗證假說提出新詞，再更新詞庫、聯合求解與修正碼組候選。關閉人工覆核即可自動連續執行；候選絕不自動標記為已驗證明文。分析期間使用啟動時的案例快照；新增情報請重新啟動分析。

預設 0 輪完全離線；大於 0 輪且再次確認後，才會傳送研究案例給已儲存的本機／內網 LLM 或明確授權的外部 DeepInfra。

參考 AI 模擬病人的 Provider/Model 設定概念，支援本機／內網 LLM 與明確授權的 DeepInfra 官方 HTTPS。DeepInfra 是外部付費 API：執行時會將密文、背景情報與候選傳至第三方。預設禁止外傳；金鑰只從環境變數讀取，不儲存於 config.yaml。

只查詢供應商模型名稱，不傳送密電或執行付費推論；查詢失敗時仍可手動輸入模型 ID。
Ollama 常用 Port 11434，例如 http://192.168.0.134:11434。修改後請先按「儲存設定」，再測試已儲存的端點；未指定 Port 的 HTTP 會連到 80。
填入環境變數名稱，不是 API Key 本身。
預設 8,192。只限制單次輸出，不是上下文或帳戶花費上限；截斷時最多重試一次，可能增加費用。

RFC1918 代表 10.x.x.x、172.16～31.x.x、192.168.x.x 私人 IP。只有當模型服務在其他內網電腦時才需要勾選；本機 127.0.0.1 不需要。系統仍會核對指定 IP 白名單。

DeepInfra 是外部 HTTPS 服務，不需要勾選內網 IP 授權。僅允許固定 API 網址；請先設定 DEEPINFRA_API_KEY 並勾選外傳同意。測試模型清單不傳案例，也不會執行付費推論。

詞彙與語言先驗

編輯會直接影響解碼候選與頻率分布；權重不是已驗證答案，範例句為 token 清單，一句一行，以空格區隔。

什麼是先驗權重？ 在看這封密電的直接證據之前，研究員預先給詞組的偏好強度；例如「車隊＝5、橋梁＝2」只是讓其他條件相近時車隊比較容易被提議，不代表 5 倍正確率或 50% 信心。降低權重可做消融比較，確定明文只能由可靠逐碼明密文對建立。
