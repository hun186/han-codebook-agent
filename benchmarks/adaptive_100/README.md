# Adaptive vocabulary 100-message trial — public synthetic replay

## What is included?

This is the **2026-10-28 previously revealed** independent synthetic study. It is
**not** the earlier 100-message study, and **not** a live GPT-6 API evaluation.
GPT-6 helped design round-three vocabulary suggestions, but all code-to-word
assignment was generated by the deterministic no-gold Python one-to-one solver.

- **100** synthetic coded telegrams, **60** different randomly-assigned cipher
  groups, **852** code-group occurrences and **34** third-party observations.
- Round 1: 27 fixed lexical candidates, 8/60 codes correct (13.33%), 156/852
  occurrences correct (18.31%).
- Round 2: 21 new words from public sender/recipient/observation evidence,
  28/60 (46.67%), 444/852 (52.11%).
- Round 3: 29 additional domain vocabulary candidates, 31/60 (51.67%),
  470/852 (55.16%). Despite full true-word coverage, 29 codes still incorrect.
- Ablation with the full 77-word vocabulary but without auxiliary evidence:
  4/60 (6.67%), 50/852 (5.87%).
- Completely correct telegrams: **0 of 100** in every condition.

**Interpretation warning:** the corpus has a privileged synthetic six-role
structure (unit, action, object, location, time, status), and observations
are unusually informative. Performance must not be generalized to unstructured
historical intercepted traffic. There is no human review in this evaluation.
A previously revealed case cannot be retested as an independent blind test.

## Paths

- `build_fixture.py` — deterministic public messages and held-out scoring
  key under `reference/` (never copied under `vercel-demo/`).
- `run_no_gold.py` — reproduces locked fixed/expanded mappings, without any
  access to `reference/`. **No real LLM API calls.**
- `score_after_lock.py` — reads reference only after mapping is locked;
  produces `han_adaptive_new_metrics.json` and 60-code comparison CSV.
- `make_report.py` — generates a **Word report with a 60-code comparison and
  every one of the 100 telegrams** as a per-telegram appendix. Each entry
  includes numeric ciphertext, date, sender, recipient, observations,
  model/solver's final reconstructed segments, reference plaintext,
  and per-position correctness.
- `han_adaptive_new_public.json` — published unscored input.
- `han_adaptive_new_predictions_LOCKED.json` and
  `han_adaptive_no_aux_LOCKED.json` — frozen predictions.
- `reference/han_adaptive_new_gold_PRIVATE.json` — **published reference
  answers for scoring only; "PRIVATE" means isolated from inference, not
  a claim that this public GitHub file is confidential**.
- [Download complete Word report](../../vercel-demo/reports/adaptive_100_full_report.docx)
  (also served at `/reports/adaptive_100_full_report.docx` in the demo).
- `vercel-demo/data/adaptive_trial_100.json` — a browser-safe compact
  bundle containing original evidence, frozen predictions, summary statistics,
  but **NO ground-truth code-to-word mapping**.

## Reproduce locally (Python 3.10+)

```bash
python -m pip install numpy scipy "python-docx>=1.1,<2"
python benchmarks/adaptive_100/build_fixture.py --output-dir benchmarks/adaptive_100
python benchmarks/adaptive_100/run_no_gold.py --data-dir benchmarks/adaptive_100
python benchmarks/adaptive_100/score_after_lock.py --data-dir benchmarks/adaptive_100
python benchmarks/adaptive_100/make_report.py --data-dir benchmarks/adaptive_100 --out vercel-demo/reports/adaptive_100_full_report.docx
```

Check frozen result SHA-256:
`960a0394a9bb2d873f81987fa4b3f31138cccb7ac8ef5ac60a12269e368ab86a`.
The GitHub Actions workflow `publish-adaptive-100.yml` regenerates and
commits the data, DOCX and Vercel-safe snapshot to this development branch.
The reference plaintext must never be supplied to the solver or browser's
mock API.

## Browser demo

From the Vercel case selector choose `adaptive_trial_100`.
With an unchanged case, **static** and **automatic** modes display
recorded results only. Use **3 rounds** plus metadata to see 8 → 28 → 31
correct code mappings; switch metadata off for the published no-aux
third-round ablation (4). This is a **replay** of historical outputs, not new
inference. The human-review mode is a separate interactive MOCK exercise:
any manually edited case or vocabulary is not the locked reference experiment.
To inspect actual accuracy, use the Word report, since publishing answer
mappings in the browser's inference data would contaminate a replay.
